# 风格适用商品与案例

十种风格覆盖常见的日用、家居、服装配饰、护理、数码、工具、文具和户外商品。用购买理由和场景来选择风格，同一品类可以有多个合适的方向。对品牌风格已经明确的任务，按其规范调整。每种风格另有虚构商品主图案例与相应详情画面的设计简报，见 [风格案例简报](style-case-briefs.md)。案例用于展示一体完成的电商画面，不作为版式复刻模板。
