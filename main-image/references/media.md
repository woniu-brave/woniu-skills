# 媒体工具接入

开始成品任务时确认当前环境能否查看商品素材、以参考图生成或编辑，以及取得可访问的结果文件。根据工具实际支持的画幅、格式、参考图数量和模型选项设置参数。识图与生图可以由不同工具完成。

| 环境 | 接法 |
|---|---|
| Codex | 使用当前会话可用的内置图片工具，例如 `image_gen`。编辑时传入本地商品参考图和本张卡对应的指令。把核验后的结果放到项目输出目录 |
| 其他助手或工作台 | 读取 `SKILL.md`，按平台支持的方式配置工作目录和图片工具。将身份、局部证据和风格参考分别映射到工具输入，按下方要求记录结果 |
| 外部图片 API 或人工制作 | 使用用户指定的接口或图片软件。规划卡、提示词和文件名可以直接交给执行方。等实际出图并完成检查，再更新任务状态 |

交接至少包含图片编号、制作意图、提示词、带角色的参考图、目标比例和像素、指定模型（如果有）、目标文件名。结果记录图片编号、真实文件路径、实测宽高、工具与模型（能确认时）、是否通过和原因。如果只拿到异步任务 ID，保留 ID 并等真实结果或显式失败。根据宿主能力恢复该任务，避免重复提交已在执行的请求。

有多种可用模型时，根据任务选图文排版稳定或产品保真表现好的路径。用户明确给的模型、档位和画幅只有在工具支持时传入。无特定画幅要求时，主图可从正方形开始，工具支持时可按 2048×2048 工作。保存原始出图和验收后的文件记录，交付尺寸以实测为准。

工具缺少参考图编辑能力时，先尝试用商品实拍、裁切和排版完成关键证据图。只有文字能力时交付规划卡及可移交的提示词，批量图片保留待生成状态。工具不能按目标尺寸生成时，先用支持的原生画幅，再按实际需要等比处理并重新检查。
