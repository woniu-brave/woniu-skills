# 品类与图型

根据买家需要看懂的内容和实际素材选择图型。下表是适用于多类商品的起点，图数、内容和顺序由用户要求、商品特征及证据决定。

| 商品类型 | 优先核对的锚点 | 主图候选内容 |
|---|---|---|
| 服装鞋包 | 款色、轮廓、纹理、门襟、缝线、五金 | 上身或携带、正背面、材质特写、收纳、尺码或实测尺寸 |
| 美妆日化 | 包装、泵头或瓶盖、标签、质地、净含量 | 包装主视觉、开合取用、实拍质地、使用场景、标签规格 |
| 数码家电 | 型号标识、按键、端口、售卖配件 | 全貌、接口标识、连接操作、桌面场景、兼容清单 |
| 食品生鲜 | 包装与标签、可见形态、份量 | 包装实物、切面或质地、食用方式、规格与配料 |
| 家居家纺 | 轮廓、支撑结构、实测尺寸、表面材质 | 房间摆放、细节、分区收纳、尺寸和安装 |
| 母婴亲子 | 商品与配件、接触面、安装方式、标签 | 商品全貌、使用步骤、配件细节、已确认适用范围 |
| 运动户外 | 轮廓、连接件、收折状态、穿戴或使用方式 | 外观、穿戴或架设、携带状态、部件和场景 |
| 其他实物 | 外观、辨识部位、包装、可验证用途 | 商品全貌、关键局部、使用场景、已确认规格 |

实拍可以证明外观、标签和可见部件。官方商品资料或商家确认可支持规格与性能说明。场景图片表达摆放或使用关系，不作为性能测试依据。只有正面图时，按 [机位流程](product-views.md) 准备所需视角，经授权推演的背面可用于外观示意；内部结构与实测对比仍需要实物证据。

同系列存在不同颜色、口味、容量或套装时，为素材标注适用变体。套装图片区分售卖包含物与场景道具。整套图保持色彩、光线和字体一致，同时用不同视角、焦点或版式展现每张图的主题。

## 挑选五张的顺序

以当前商品的购买决策为准。缺少某张的证据可用其他值得展示的问题替换。多个 SKU 共用这些品类名，图型命名用买家能看懂的词。

| 商品类型 | 首图之后的四个候选位置 |
|---|---|
| 服装鞋包 | 版型与上身、织纹、搭配或使用、工艺细节 |
| 美妆日化 | 包装开合、取用或质地、梳妆场景、标签近景 |
| 数码家电 | 外壳和表面、端口或控制区、使用位置、关键做工 |
| 食品生鲜 | 包装识别、可见切面、食用场景、份量或标签 |
| 家居家纺 | 表面特写、结构和安装、室内摆放、接缝或底部 |
| 母婴亲子 | 接触部位、操作与组装、实际使用场景、配件说明 |
| 运动户外 | 材质、连接或收折、使用环境、抓握和承力部位外观 |
| 其他实物 | 材质、可见功能部位、摆放或操作、细节 |

## 不同品类的起稿组合

下面给出的是策划起点。用户的张数、投放要求与当前商品的实际证据优先；缺少对应证据时替换主题，不伪造结构。

| 商品类型 | 识别位 | 外观或质感位 | 理解位 | 使用位 | 信任位 |
|---|---|---|---|---|---|
| 服装鞋包 | 商品全貌或获准上身 | 面料、皮纹、表面 | 版型、收纳或可见分区 | 搭配、携带、日常场景 | 领口、缝线、五金、接缝 |
| 美妆日化 | 瓶型与包装 | 质地、表面、印刷 | 开合、取用与真实用量 | 梳妆、浴室或外出环境 | 标签、净含量、包装细节 |
| 数码家电 | 真实外形与型号 | 材质、接口、按键 | 操作流程或可见部件 | 桌面和连接关系 | 接口排列、标签与随售配件 |
| 食品生鲜 | 包装与商品外形 | 可见切面和质地 | 有资料支持的成分或处理方式 | 餐桌、食用方法 | 标签、净含量及可查信息 |
| 家居家纺 | 房间中的整体尺度 | 表面和织物特写 | 已知连接、分区或安装 | 居家摆放与动线 | 做工、配件及实测尺寸 |
| 母婴亲子 | 商品全貌与接触位置 | 表面材料 | 已核实操作步骤 | 使用场景 | 配件与已确认适用范围 |
| 运动户外 | 商品整体与穿戴状态 | 材料、握持位置 | 连接、折叠或穿戴方式 | 有实际用途的环境 | 接缝、扣件及标识 |
| 其他 | 整体识别 | 可见材料和外观 | 可解释的结构或用法 | 商品实际所在场景 | 标签、边缘与确认过的规格 |

可按调性选择质感陈列、简洁利益点或生活方式。质感陈列强调有层次的布光和清楚轮廓。利益点图给一个突出的已确认卖点。生活方式画面以产品和空间的真实关系为主。实际投放位限制优先，选哪个风格和用哪种语言都取决于任务与市场。

## 投放位置和语言

先区分平台所指的第一张主图、后续商品图及广告素材，再定是否带字、背景和占画比例。平台给定主图白底、纯商品、禁新增文字等规则时，首图单独按规则做，卖点文字移到允许的副图。淘宝、天猫、京东、拼多多、抖音、小红书或 Amazon 等平台的具体尺寸与约束，以任务要求和当期官方说明为准，保留引用。可把 1:1 作为没有平台要求时的通用主图起点，可按用户要求导出竖版。语种取用户指定或商品资料的目标市场，转写时保留真实品牌与型号，逐字核对正式文字。

对 Amazon 等明确规定主图形式的平台，把合规商品展示图与信息型副图分开制作；商品实物或包装自带的文字与后加促销字分开判断。平台规则可能更新，开始任务时查当前官方规范，不把历史比例、占比或文案限制写死。用户指定其他语言不代表自动切换平台。平台、图型和商品类型有冲突时，先满足具体投放位规则，再用允许的副图表达剩余信息。
