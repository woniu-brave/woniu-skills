# 主图制作手册

此手册说明如何把商品档案转成一组可执行的单图任务。入口的资料提醒与用户授权、款色绑定规则、视觉系统和平台要求适用于本手册全部步骤。主图与详情页同做时复用[共享商品档案与创意边界](product-asset-record.md)。外部表格或网页采集只在用户指定且当前工具可访问时接入；本地多款任务见 [批量制作](batch.md)。

## 建立可信商品档案

按款色记录：款号与商品名、正背侧与俯视外观、比例、主要部件的相对位置和数量、开口与连接方式、表面颜色和材质观感、纹理、边缘、缝线、按键或接口、标签文字及配套物。服装再记录领口、裁片、袖口、腰头、口袋、衣摆和版型；不同品类将这些位置换成有区分价值的结构。

每个档案条目写清依据：用户确认、原图可见、可靠资料或获准推演。商品原图负责锁定已知身份与特征；白底图用作轮廓基准；局部照片负责对应细节；机位素材控制本图角度；风格图只负责其明确指定的颜色、光线或气质。推演机位不能倒过来证实商品事实。售卖附件、布景道具和包装内容分开记。

接收实拍时先整理干净的商品基准，再准备本组所需视角。多个原图交叉确认商品整体与局部；只有一个视角时，按计划生成补充机位。把用户指出的模糊处单独列明：等待补图或明确授权后，保持已知部分不变，使用常见外观完成示意，并标记需核验的部位。用户限定只能使用实拍时，不生成或伪称存在其他商品角度。

## 规划整组图片

先确认目标站点、图片投放位置、数量、画幅、语言和任何平台规定。具体平台规则会变化，成品任务需要时查阅当期官方说明，并区分搜索首图、商品副图、广告素材及详情页。用户已定的风格与文案沿用；未指定时，从商品类型、证据、买家顾虑和视觉参考中选方向。

没有自定义数量时，可以从五个购买问题开始：这是什么、材质或表面怎样、能看到什么结构、在何处使用、哪些局部值得核对。按 [品类与图型](category-routing.md) 替换不适合的主题。组织顺序可先识别商品，再给质感与结构证据，接着展示真实使用关系，最后补上关键细节。每张只承担一个主任务；没有资料支持的模块换成能证实的内容。

给整组定一套可复用的色板、主辅光、背景材料、明暗、景深、文字层级和图标笔触。然后按[构图资料](composition.md)为每个购买问题选不同的构图方法，整组的主要构图骨架应彼此区分，避免多张只换标题或裁切。多图的统一感来自用光、色调和字体；不同感来自机位、景别、焦点、主体位置和信息路径。只有需要公平比较真实款色或状态时才固定相同角度。

## 单图制作卡与提示词

每张图先写一张短卡：

- 编号、款色、投放位置和买家问题。
- 商品基准图、视角图、局部图和风格图分别起什么作用；哪些特征必须保留，哪些外观属于推演。
- 机位方向与高度、画面景别、商品位置、前中后景和视觉动线。
- 第一焦点、第二焦点和最后的信息落点；标题、短文案、需要核对的事实以及必须留出的区域。
- 图标、引线、局部窗、色块、场景道具与真实商品部件如何对应。
- 输出比例、目标尺寸、文件名、限制和本张验收点。
- 人物仅在用户允许时加入；入镜后检查脸、手指、关节和肢体比例自然，人物动作不遮挡商品关键结构。

把卡片扩写为针对当前生图工具的自然语言任务。提示要包含约 6–8 个辨识度高且有证据的商品特征；参考图按角色说明，避免把风格图误当商品依据。画面段写清主题、光线、空间、商品朝向、第一与第二焦点、文字区域和阅读顺序。不得只复述商品长相而不给镜头任务，也不得重复第一张成品的布局来维持所谓统一。

将每张生成任务组织为五段，按工具长度限制压缩冗余修饰语，不压掉事实约束或机位指令：

1. **商品身份**：款色和 6–8 项已确认锚点，明确参考图锁定的内容。
2. **本图目标**：一个买家问题、图片在套图中的角色和必须呈现的可见证据。
3. **镜头与设计**：机位、景别、主体位置、前中后景、光线、空间材质和视线路径。
4. **图文安排**：固定文案原文、可拟文案的事实范围、字阶与对比、图标或引线终点、文字与商品如何处于同一画面关系。
5. **边界与输出**：不得改变的结构、不得新增的品牌元素/部件/参数、平台要求、比例、尺寸及输出名。

默认由模型围绕已锁定的商品身份设计具体画面，不为每张图硬编码同一套卡片位置。用户给出明确排版或参考图并要求沿用时，才改为尺寸化的版式复现路线。

用户提供或确认的品牌字样、品名、型号、成分、数值和单位按原文核对。用户允许代拟文案时，可以请模型从已确认的主题、受众和语气发展简短标题或标签；它只能表达已知事实，不能增加材质、效果、兼容、容量、检测或背书。活动价格、折扣、销量、日期、认证和服务承诺必须同时有用户依据、明确入图授权及合规投放位置。中文用简体，其他语种按指定版本制作。平台禁字或用户要求无字时，不在画面生成营销文案。

要求成品画面时，应让商品、场景、文字、图示和光影共同构图。让标题落在真实留白或与商品边缘自然呼应；引线终点落在正确部件；卡片和图标只有在解释内容时才加入。不要把画面拆成一张无字商品照外加漂浮标题，也不要给每张图套相同圆角标签。精确文字可在既定版面和预留位置局部修正，不能借排版修改商品。

## 生成与任务恢复

单张任务应明确参考素材、模型用途、支持的比例与画幅、语言和输出名。工具支持时可使用其编辑模式及对应商品图；不支持的字段不传入。约 2K 可作为常见工作目标，1:1 可作为未指定主图比例的起点。具体模型、像素和文件格式取工具当前 Schema 与回传文件为准。任何预设裁切、补边或缩放都要先保护商品轮廓和文字；不能无损满足时重新构图。

同一组尽量沿用能稳定保持商品身份的路径。每张记录本图 ID、输入文件角色、提交参数、异步任务标识（若有）、状态、输出路径、像素和验收结论。先查回已有成品与仍在运行的任务，再从失败或缺失的位置继续。检查错误后仅重做相关图，不覆盖已通过文件。若只有文本生成能力，交付完整制作卡和仍待执行的图项，不把提示词说成已生成的图片。

## 套图验收

每张放大检查外观、颜色、数量、纹理、标签字样、场景比例、文字拼写及所有指向关系；与档案核对新增或改动的细节。模型加出的无依据文案直接移除或重做。缩至实际投放位检查商品是否一眼可认、主副层级是否清楚、背景和文字对比是否足够。

整组并排检查款色绑定、视角与构图是否真正变化、首图是否符合投放位，以及副图是否各有证据任务。交付逐张给出可查看与保存的文件入口；主图、详情图、白底图和本套实际使用的多机位素材分开提供。用户要求继续时回看本轮状态，只补缺图。
