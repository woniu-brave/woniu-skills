# 主图构图库

先选购买问题，再选构图。首焦点必须能在缩略图里辨认，第二焦点放证据，最后才读标签或补充信息。同一套尽量给功能不同的图片安排不同的构图，保留统一的色彩与布光。

给每张图挑一个主要画面骨架，并明确三层视线：首焦点、证据焦点、文字或细节落点。可再选一个适合当前商品的动势，例如偏轴、局部越格、字与商品轻微叠压、尺度变化、弧线引导、成片留白或让非核心道具出画。没有设计收益时省略动势，不把装饰动作当成硬性打卡项。

| 构图 | 怎样安排 | 适合回答的问题 | 验收要点 |
|---|---|---|---|
| 错位平衡 | 商品偏左或偏右，由另一侧标题、色块或光斑平衡 | 商品是什么，首图看哪里 | 缩略图主体仍突出，文字留在空区 |
| 文图穿插 | 标题与主体边缘呼应，少量前后交叠 | 卖点能否一眼读懂 | 避开商标、端口与产品轮廓关键部位 |
| 系列陈列 | 多变体按同一视角与尺度排列，以顺序或色差引导 | 有哪些颜色、口味或系列 | 真实变体齐全，每格标签与实际商品对应 |
| 平铺拆解 | 把主件和可见部件或盒内实物按组平铺 | 有什么部件，买到什么 | 数量一致，可选配件标清，实售和道具易分辨 |
| 场景加局部 | 大场景交代使用关系，小窗口放有据可查的局部 | 使用时怎样，关键细节在哪里 | 窗口指向同款部位，避免复用整套已有特写 |
| 前中后景 | 近处给尺度，商品在中景，远处交代环境 | 商品摆放或使用后效果如何 | 主体未被前景挡住，尺度可信 |
| 并列对照 | 两列或三列保持角度、光线和标尺一致 | 两个实际规格或状态有什么区别 | 对照对象及条件来源明确，差异可直接读出 |
| 大小错落网格 | 一格为主，其他格辅助，使用统一间距 | 多个结构或局部怎样理解 | 主次明确，格数与证据量匹配，细字不拥挤 |
| 商品配特写 | 一张主体图居中或偏轴，周围用一到三处细节辅助 | 同时了解全貌与做工 | 每个窗口的来源和位置准确，商品仍是第一焦点 |
| 围绕中心 | 商品为中心，用方向、光影或短标识向外组织 | 商品和营销信息怎样共同引起注意 | 读得清商品轮廓，活动信息经确认 |
| 图文分区 | 用横竖分区安排商品、规格或简短的卖点卡 | 有什么参数，怎样选 | 焦点集中，内容按顺序读，规范数值不压商品 |
| 靠边留白 | 主体靠近一侧，另一侧留连续空域 | 如何突出单品或留出标题空间 | 主体朝画内，边缘未裁掉重要部件 |
| 环境框景 | 柜格、门洞、台面边界等围出真实观看区域 | 商品在特定环境中如何使用或陈列 | 框内干扰少，框景未遮挡商品 |
| 三点布置 | 用主体和两个次要元素形成清楚的三角重心 | 如何组织使用中的商品与附件 | 附件与商品有用途联系，主件最醒目 |
| 斜线引导 | 用商品轴线、台面或动作方向带出动势 | 怎样展示有方向的动作或长形商品 | 斜线引到商品，角度不会误导真实形状 |
| 居中对称 | 以垂直轴线对齐画布及商品，控制边距 | 外形、标签或正面结构是什么样 | 阴影、畸变和透视不会改变商品形态 |

优先把留白、错位平衡、层次、网格、对角线或引导线应用到具体商品。曲线、螺旋和透视可以作辅助手段，从现有场景里找路径，避免为套构图而改变商品形状。增加遮挡、跨格或尺度变化时，每张选择一项能改善阅读的动作。

首图需纯商品时，优先居中或简单留白，按目标平台的背景、主体比例与文字规则制作。复杂的文图构图适用于允许展示说明的副图。做强对比、容量或功能演示时，先核对实际条件和实物来源。

可以让场景材料承托商品，让光线沿机身或布料纹理行进，或让真实操作方向带出阅读路径。组件共享一套视觉语言，但标签可根据内容使用不同形状、颜色或材质；不要把所有说明塞进相同半透明框。摄影、印刷、拼贴或手绘方向可选择少量颗粒、漏光、纸感或线条变化。只在不影响商品、文字和边缘准确性的区域加入这些细节。
