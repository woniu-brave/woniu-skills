# Main Image

根据实拍和商品资料制作首图、主图套图或多 SKU 批量素材。入口为 [SKILL.md](SKILL.md)。

## 在助手或工作台中使用

1. 保留 `main-image` 目录和内部结构。按当前助手的导入方式添加 Skill，或在任务里指定读取 `SKILL.md`。
2. 提供商品图及已知信息。有不同颜色或规格时注明对应图片。示例请求为「给这款雾蓝收纳盒做一张搜索首图和四张副图，突出开口、锁扣和叠放。场景和文案由你设计。白底与实际用到的机位图也分别给我。」
3. 根据 [媒体工具接入说明](references/media.md) 连接所用平台的图片工具，或把制作卡交给执行方。需要本地批量时，以 [CSV 示例](references/batch-example.csv) 建任务清单，用 Python 3 运行 [批量流程](references/batch.md) 中的命令。

单品规划与提示词可在文字环境完成。实际图像需要当前环境具备参考图编辑能力，或由执行方提交已核验成品。本地批量脚本管理任务和结果，生图由所选工具执行。
