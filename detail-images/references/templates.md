# 详情页视觉参考库

选择色调、光影和排字时可查看 [风格模板](style-templates.md)、[风格适用商品](style-cases.md) 和[原创案例画面制作简报](../templates/style-examples/index.md)。这里的逐屏模板用于规划内容顺序和版式。

服装实拍可直接查看 [完整七屏样稿](../templates/apparel/index.html) 和 [服装逐页规划](apparel.md)。这套示范展示首屏、全貌、细节、款色和款式信息如何用不同图框串起来。

完整详情页通常为 7–14 张独立图片。下面的模板按页展示首屏、主体、局部和收尾的阅读顺序，每套提供 11 或 12 个 3:4 页面。空白图位只是用来规划照片构图，制作时换成当前商品和实际文案。HTML 可以切换到 375px 手机长页，也可以通过导出脚本获得独立的逐页文件。

| 模板 | 页数 | 内容顺序 | 文件 |
|---|---:|---|---|
| 外观与工艺 | 12 | 首屏与外观 → 肌理和做工 → 上身与搭配 → 款色、规格与收尾 | [总览](../templates/layouts/craft.svg) · [可编辑 HTML](../templates/layouts/craft.html) |
| 场景与搭配 | 12 | 环境与商品 → 摆位与用途 → 触感与搭配 → 尺寸与确认 | [总览](../templates/layouts/scene.svg) · [可编辑 HTML](../templates/layouts/scene.html) |
| 功能与操作 | 11 | 用途与功能 → 结构与原理 → 步骤与效果 → 适配、问题与清单 | [总览](../templates/layouts/use.svg) · [可编辑 HTML](../templates/layouts/use.html) |
| 规格与选型 | 12 | 规格差异 → 并排和参数对照 → 测量与试摆 → 下单信息 | [总览](../templates/layouts/spec.svg) · [可编辑 HTML](../templates/layouts/spec.html) |
| 包装与使用 | 11 | 包装外观 → 开盒与内含 → 步骤与场景 → 标签、保存和收尾 | [总览](../templates/layouts/pack.svg) · [可编辑 HTML](../templates/layouts/pack.html) |

没有用户参考图时，先选一套决定首屏和整页气质，再从一至两套补需要的模块。保留各块回答的购买问题，按当前商品重排顺序。统一修改背景、强调色、标题字级、边距和光线。例如服装可使用外观与工艺的姿态及近景，搭配规格与选型的并排表格呈现实测尺码或色号。

想看如何把照片和文案放入单页，可打开 [工艺](../templates/previews/craft.svg)、[场景](../templates/previews/scene.svg)、[操作](../templates/previews/use.svg)、[选型](../templates/previews/spec.svg) 或 [包装](../templates/previews/pack.svg) 的局部填图示例。对应 HTML 位于 `templates/`。

## 调整一屏，保留整套视觉语言

模板是可编辑的参考。单屏需要按商品机位和买家问题重排，可从下列关系选一种，标题、图例和背景延续套系色板。手机线框可从 24px 左右的内容边距和约 8px 的屏间分隔起步；字号依据一屏字量及手机预览调整。用户指定测量版式时用实测参数。

| 买家需要看清的内容 | 可组织的画面 |
|---|---|
| 一眼认识商品 | 大场景保留自然放置关系，标题借场景空域落位，关键短标贴近对应部件 |
| 快速理解多个卖点 | 主体偏中，在周围按部件分布图标短标，线条和标签与轮廓拉开距离 |
| 解释设计怎样解决问题 | 从可解释的真实结构进入，用箭头或简图说明作用路径，保留实拍证据 |
| 看商品在不同位置的表现 | 借场景线条、色块或连续光线串接多机位小景，地点标记与各画面绑定 |
| 看款色或规格差异 | 同视角同光线并排，先显出区别，标签列真实色名、款号与条件 |
| 验证做工 | 用实际细节贴近主体，放大窗连接实物接缝、纹理或边缘 |
| 看使用过程 | 按动作编号与方向布置靠近商品的图示，流程能从起点顺着读到结果 |
| 查包装、实售范围与认证 | 产品照片做视觉锚点，各组成和资料紧邻相应部件，认证需有可复核文件 |
| 选尺寸或操作位置 | 保留清楚的产品参考视图，使用对应的引线或表格，测量依据与数字相符 |
| 收尾与重要信息复核 | 用代表性机位简洁重申已证实规格或买家最需要记住的信息 |

场景间可沿用同一材质或温度的配色，证据页适当简化布景，形成阅读快慢对比。若画面是多色并排或使用步骤，可保留明确分区；同一套中避免连着使用完全相同的图框配置。
