# 电商图文字排版

参考美工美邦关于详情页文字分层、对齐和视觉平衡的分析。优设页面的主要内容嵌在图片内，当前未能完整提取，以下规则结合了同一作者另一篇可读取的文字文章和本项目的设计实践。[用户提供的优设文章](https://www.uisdc.com/detail-page-layout) · [同作者的相关文字文章](https://www.ganhuoku.cn/archives/155244)

## 先定文字层级，再找文字位置

1. 给这张图写一句购买问题。在首图以商品可辨和一个购买理由为先，在详情页把它写成该屏唯一主标题。副标题说明适用场景或理由，标注解释一个看得见的部件，规格保留单位。把同一件事的标题、解释和证据归到一起，用字号、字重和组间距拉开层级，删去重复卖点。
2. 先看商品轮廓、动势、最醒目的光影和道具，找能容纳整组文案的干净区域。在主体和空间都稳定的画面尝试居中。主体或道具更偏向一侧时，把文案放到另一侧可读区域，短句可右对齐，较长正文通常左对齐。即使主体居中，也可以利用窗框、墙地交线或产品长边建立左、右对齐轴。先定轴再编辑换行，短语和数字单位保持完整。
3. 先在照片构图里为文字留位置，再确定机位和光线。标题可落在墙面、天空、桌面或虚化暗部，说明紧随标题或贴近对应图像证据。用字号、字重、行距和对齐区分信息，必要时顺着原有光线控制字后局部明暗。结构短标和小图标沿引线组织，端点落在实际部件；动作箭头指明路线；尺寸数字沿标尺排。短标可以有轻描边或弱底色，尺寸应紧随内容。规格表等需要独立查找的内容按信息结构排版。
4. 先定首屏、段落标题、正文和参数的字阶，再按商品和阅读顺序选择布局。首屏要形成明确的第一眼焦点，段落标题短而具体，正文在手机上能连续读完。相邻段可以交替用通栏图注、左右图文或居中短标题，保持对齐轴和间距有联系。按语意断行，数字和单位留在同一行，一小截文字孤立换行时优先改文案或缩窄信息范围。

## 制作与验收

- 在制作卡或分屏表记录「购买问题｜主标题｜副文案或证据｜商品重心｜文字对齐轴和可用留白｜标注终点」。把这些位置关系写入整图提示词。规格、型号和关键中文如需准确排字，沿同一场景保留的轴定位。
- 750px 宽长图可从首屏 64–82px、段落标题 42–54px、正文 27–30px、短标 22–26px 起稿。宋体的笔画粗细、正文长度和版面宽度都会影响实际读感，须在约 375px 宽实看。
- 在手机宽度查看首屏、结构段、场景段和参数段，检查第一眼层级、断行、行距、标尺单位和标注落点。逐段指出文字借用了照片里的哪块空间，以及读者从文字能找到哪一处画面证据。字被挤出场景时，回到照片构图补留白后再导出。
