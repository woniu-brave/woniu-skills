# 服装实拍详情页

可从 [七屏填图示范](../templates/apparel/index.html) 借鉴阅读顺序和信息结构。它是虚构的实拍型线框示范，原目录的照片和文案只供参考；不得把替换图片和文案的模板导出作为默认成品。用户允许生成且工具可用时，按主体、场景、文字统一构图生成完整画面，再在长画布中设计衔接。用户只允许原片或需要精确表格时，可把模板作为可编辑起点，但仍需为实际商品重新设计照片与文字的空间关系。

| 模块 | 回答的问题 | 构图 | 素材条件 |
|---|---|---|---|
| 首屏 | 这件衣服是什么风格？ | 大幅全貌，标题与图片交错 | 单件清晰正面或获准的上身 |
| 廓形 | 正背面有什么区别？ | 同比例并图，标清角度 | 同款真实正背面。仅有正面时，可用全貌配特写指出版型关系 |
| 面料 | 近看是什么纹理？ | 大幅微距、短解释 | 实拍近照。成分须有资料 |
| 结构 | 最特别的一处在哪里？ | 细节大图，文案分区 | 对应领口、开合、肩线或装饰近照 |
| 局部并看 | 两处收边或结构如何配合？ | 错位分栏或同尺度对照 | 两处真实且可区分的细节 |
| 款色 | 颜色在实拍里是什么样？ | 色名结合大面积实拍 | 单色用真实面料或整件照片。多色用同款各变体图 |
| 款式信息 | 下单前要记住哪些已知信息？ | 信息卡或可读表格 | 只列本款已确认的信息 |

需要扩展至 8–14 页时，只加入有独立证据的肩袖、扣位、下摆、真实上身、搭配、尺码等模块。完整详情一般为 7–14 张，材料不足时先列缺项，合并重复信息并注明实际页数。对应源照片有冲突文字时按素材与验收规则处理。

`pages.js` 的 `panels` 按交付顺序排列。可选版式为 `cover`、`pair`、`macro`、`split`、`duo`、`color`、`facts`。每页提供独立 `id`、`title`、可选的 `note` 和 `images` 或 `facts`。照片对象支持 `src`、`alt`、`caption`。拼图可加 `crop`（源图宽高及安全区域 `[原宽, 原高, x, y, 宽, 高]`）。需要展示完整扣位、开合或零件时，可指定 `fit: 'contain'` 并逐一在成品中核对。分栏支持 `photoSide: 'left'`。导出前检查领口、两袖和下摆是否完整，正文在手机宽度下能否读清。

在技能根目录导出示范页：

```text
node scripts/export-panels.cjs templates/apparel/index.html ./apparel-export 750
```
