# 素材与成品验收

## 两套图共用一份商品记录

用 `product.json` 或等价的 Markdown 记录以下内容。主图与详情页一起做时复用同一份文件，单独调用任一技能也能独立完成。

- 款号、正式品名、色名、平台、交付尺寸、用户授权和禁用项。
- 事实清单按“用户提供 / 照片可见 / 未确认”标注来源。只有前两类可以作为已证实的画面细节或文案依据；经用户明确授权后，未确认结构可按常见设计推演为 AI 示意，按 [商品白底与多机位](product-views.md) 单独记录并提醒核对。图片自带标题、营销文字、品牌宣传和色差说明应单独标记，不能直接继承为本商品事实。
- 每份素材有 ID、款色、角色和使用状态：可直接使用、仅可用已检查的裁切区域、仅供核对、排除。需要裁切时记录安全区域或裁图路径。识别图上的人台布面、支撑杆、夹具、背景物、边框和原文字。用户禁用的元素即使被纱网透出，也不能留在成品。
- 每张成品记录输出 ID、购买问题、素材及裁切、实际制作方式、像素、预检结论与路径。回看时能从成品查到具体原图。

## 用素材做图

优先使用清晰、已确认款色的单件图。拼图先拆成单件安全图位，排版时重新加需要的标题和正背面标记。带冲突标签或款色不明的照片作为核对材料，确认同款且可安全去掉无关内容后才考虑使用。素材缺少所需角度时，按 [商品白底与多机位](product-views.md) 提醒、取得必要授权并生成示意；用户禁止生成时使用经核对的素材。

风格可以通过构图、背景、排字和统一布光表达。生成工具用于获准的换背景、场景或上身时，保持商品参考和风格参考分离。回看衣身轮廓、领型、袖口、下摆、扣数、花纹与透感。结构或颜色错误不能留作成品，优先恢复实拍并重新排版。弱分辨率照片放大前看局部，选合适的使用尺寸并记录限制。

## 交付门槛

1. **图里有什么。** 对最终 PNG 逐张检查，确认禁用项及无关原图文字没有漏入，裁切边框也没有遮掉当页要展示的部件。
2. **商品是否一致。** 同款同色。主图的首图完整可辨，详情近景与原片相符。数值、品名和色名来自同一份共用记录。
3. **是否容易读。** 主图在手机列表缩略图尺度下仍能辨认商品。详情在约 375 CSS 像素宽预览中检查字级、阅读顺序和相邻页的内容重复。每个页面只保留有用的信息。
4. **文件是否可用。** 核对文件清单、顺序及实际宽高。主图、详情页各有独立入口，能直接打开每张 PNG。按具体模块返修并复查受影响的图。
