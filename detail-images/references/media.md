# 媒体工具接入

读取用户给的实拍或版式图，核对文件像素。前期使用图片工具准备白底及机位。制作环节默认用该屏的完整图文设计交接成品。参数表、尺寸数字和必须逐字准确的品牌文案可以在完整设计中用可编辑图层或 HTML 精排。

| 能力 | 接入方式 |
|---|---|
| 识图与参考图测量 | 宿主可直接查看图片时，先实测画布，再标注图块、文字和间距。可读取文件或截图时用工具复核。不支持看图时可使用用户给出的文字规格和版面测量表 |
| 生成和编辑图片 | Codex 可用当前会话提供的 `image_gen`。其他宿主使用其图片工具或用户指定的外部服务。固定商品身份时要求能读入商品参考图。根据已支持的字段选择模型、原生尺寸与格式 |
| 预览、排版和切片 | 浏览器打开本地 HTML。可运行 Node.js 和 Playwright 的环境可调用附带脚本。其他环境可把 HTML、素材和模块清单带到支持本地执行的机器导出 |
| 展示和交付 | 输出按模块排序的实际文件。工具返回异步任务 ID 时先记录，等文件取得并核验后再交付。用宿主支持的附件、内嵌图或文件链接展示 |

每次图片交接用稳定的模块 ID，给定素材角色、制作描述、目标像素、比例、实际支持的参数和输出名。结果至少记录模块 ID、文件路径、实际像素和验收状态。服务不支持指定画幅时，先选择最接近的原生尺寸，再用等比补边或保留主体与文字的安全裁切达到目标。交付标明实际像素及本地调整方式。

工具缺少整屏生成或精确排字能力时，仍可用实拍或已核验的图完成 HTML 路线。只有文字能力时交付模块制作卡、文字、提示词和可编辑线框，状态记录为待生图或待渲染。
