# 连续详情长图制作

## 先规划完整长图

为全页建立一套商品锚点、光线与字体规范，确定通常 7–14 屏的购买问题、实际文字、商品视角、长图坐标和最终切点。相邻屏用同一场景的背景、布光、边缘元素或自然过渡连接，同时给每个主题独立的镜头、景别和信息层级。屏数由用户指定优先；用户要求一个不间断长画面时，不把多张无关的成品上下拼接当作连续画面。

先判断当前工具的实际单次像素、扩图、参考图、遮罩和中文排字能力，再选择路径。一次原生生成可满足全部长度及清晰度时直接生成；否则用连续向下扩展：以上一段末尾为上下文，将下段产品参考、下一段主题和统一风格一起送入支持扩图或遮罩编辑的工具，在重叠区匹配光照、纹理、透视与结构。每段优先直接生成包含标题、说明和商品的整体商业画面；需要文字纠错时，只修正文案对应区域，不另做分离的文字条。无扩图接口时，使用可用的局部编辑工具在有重叠的接缝上修复，不伪称一次原生生成。

## 分段延展与恢复

1. 起始画面确定宽度、画面基调、商品锚点、标题系统和用户已经认可的内容。记录原始文件、实际像素、已批准的不可更改范围，以及生成或编辑方式。
2. 每次用上一母版底部一段作为上下文，规划下一个需要的视角与卖点；上传上下文图、对应商品参考及必要局部参考，指明用途。参考视角是 AI 推演时保留其来源标识。只请求延展当前缺失区域，并给后续文字留足对比度和安全边距。
3. 对输出和既有母版按实际像素对齐；重叠带只用于局部接缝修复，不能覆盖用户明确要求保留的已批准区域。接触阴影、墙地连接、光线、纹理、商品边缘、字色和文字连续检查。禁止无依据重复产品、变形或把无关区域贴在一起。必要时对接缝或当前段重新编辑，保存可回退版本。
4. 持续扩展直到全部约定屏数和内容完成。每次记录执行状态、参考素材、任务 ID（如有）、新母版文件、像素、接缝位置和验收情况。恢复时只处理缺失或未通过的区段，不重复提交完成或正在执行的任务。用户要求不中断时自行连续推进，不为每段额外确认。
5. 确认实际分辨率适合目标宽度。避免整条超长图缩到工具的单张小画幅再放大；优先保持各段的有效生成宽度。插值放大只增加像素数，不等于增加原生细节；任何缩放或压缩按实际说明。尺寸标注只使用有依据的数据，标尺两端对应实物测量位置。
6. 母版完成后沿留白切分，切点不穿过商品要点、标题、尺寸线或图例。导出逐屏图片并按像素坐标无缝还原，检查切片总高度及拼回结果与最终母版一致。长图母版和每张切片分别提供可直接打开的文件；按需要另交白底与多机位素材，不使用压缩包。

可用本包 `scripts/slice-master.py` 对实际母版执行无损 PNG 切片。先根据画面人工确定安全切点；`--cuts` 传递从上到下递增的内部 Y 坐标，脚本自动读取总高度、校验切片并逐像素比对还原结果，输出 `manifest.json`。此工具不生成或修复画面，也不判断切线是否穿过文字和产品；这些需先目视核查。需 Python 3 与 Pillow。输出选择新的空目录，已有结果不会覆盖。

```text
python scripts/slice-master.py path/to/master.png path/to/new-output --cuts 1000,2100,3200,4300,5400,6500,7600
```

## 本地扩图工作流的可用性

若当前环境已有可用的本地扩图服务，可采用参考图 + 旧图底部上下文 + 遮罩的生成工作流，按服务实际节点与模型能力配置，不假设模型、节点名、端口或依赖已存在。调用前先检查可用模型与输入、输出路径；为当前项目使用独立目录，保留原图和各阶段母版。任何模型执行结果均需打开检查，生成成功不代表接缝或文字已合格。服务不可用时使用当前具备编辑能力的图片工具完成同一目标；真正缺失能力时说明具体受阻步骤与已完成文件。
