# 商品详情页设计与制作

把购买时的疑问排成连续的阅读顺序，每段用合适的产品机位和证据回答一件事。完整详情页先设计并导出一张长图，再按内容节点切出通常 7–14 张图片。用户指定数量、比例、模块范围或只要线框时按其要求。

## 判断输入和设计路径

- 缺商品图时请用户提供当前款色的原图。**若只有商品图或笼统制作要求，先发一次资料提醒，等待用户补充、明确表示没有资料或授权代拟。** 提醒涵盖商品名和款号、色名、平台、页数或范围、核心卖点、受众与风格、文案和素材限制，以及确有依据且本次要用的材质、规格、洗护、配件或包装。主图一起制作时只问一次，复用同一份商品记录。
- 优先用用户给出的文案、语种和投放规格。允许代拟时可写营销文案、名称建议和视觉方向，所用尺寸、认证、配件、效果和结构证明须来自已核对的商品资料。只知道外观时，用同款实物、可见设计和确认过的使用信息给买家建立认知。
- **自主设计。** 无版式要求时，按品类与当前货品从 [详情页参考库](references/templates.md) 选取合适的阅读结构和图位，换成本次商品的设计。用户发图用于说明完成度或喜欢的风格时，提取阅读节奏、信息密度、层次和图文关联，再独立确定版面、文案和场景。
- **按指定版式排版。** 用户明确要求按某张参考保留布局时，按 [用户指定版式测量](references/production.md#五用户指定版式时逐项测量) 获取像素并建立元素清单，保持约定的模块顺序、层级和图文关系，用本次商品素材及文案重新设计。需要严格对齐时先提交可核查的线框和对照。用户只要 HTML 时交付 HTML；要求先看排版时完成预览后等待意见。其余完整成品请求把线框用于内部规划，按已确认范围直接完成。

## 建立商品与视觉基准

1. **观察所有同款输入。** 提取可逐项验收的商品锚点，具体到色调、整体比例、结构相对位置、数量、外观材质、纹理走向、尺寸有无依据、接缝和标识。服装看领口、版型、透感、排扣、压线和下摆；家居看支撑、开口、连接件和摆放尺度；电子产品看接口顺序、按键和实售配件。画面里的品牌字样、原图标题和待核实信息分开记录。不同款色各有依据。更多约束见 [素材与成品验收](references/quality.md)。
2. **先备白底和机位，再定每屏用图。** 收到白底图，保留干净的独立商品图，制作场景时提取主体；收到实拍，先整理出可核对白底图，再进行机位准备。多张实拍用于相互校验全貌，可从已知形态生成更合适的展示角度。单张图也主动补齐必要机位。设计容量页可能需要俯视，结构页需要侧面，开合或接缝适合局部近景。数量和顺序服从实际展示内容，不能整页只复用同一个透视。
3. **处理看不见的细节。** 关键结构遮挡或无法辨认时，先说明具体缺口，待用户补图、解释或明确允许按常见外观补全后处理。未回复时暂停涉及该未知部位的制作；已经获得覆盖该缺口的答复可直接继续。保持可见事实，把根据单向参考配出的新机位和未知外观标为 AI 示意。未经证实的内部结构、规格或功效不能写作事实。详见 [白底与机位素材](references/product-views.md)。用户指定只用实拍时遵守该限制。
4. **建立整套视觉规范。** 按 [十种商品图风格模板](references/style-templates.md) 或用户已明确的风格，把希望传达的感受落实到商品主色与搭配色、背景材质、冷暖、主光方向、反差和景深，固化标题、副标题、短标、正文及数字的字重、字号比例、颜色、行距、对齐和安全边距。两套图可共享关键视觉参数，构图按各自载体调整。经授权使用人物时，同一套人像模块验证脸型、肤色、年龄感、发型和体型一致，用户禁止人物时用静物或环境承载。

## 把页面做成整图

将详情页做成从第一屏读到最后一屏的完整图文作品。主图与详情页同做时共用[商品档案和视觉资产规则](references/product-asset-record.md)。制作顺序、商品档案、线框和版式测量方法、工具字段、任务恢复与单屏返修统一见[详情页制作手册](references/production.md)。

1. 先按[详情页制作手册](references/production.md)核对平台与投放位置的当前规格，再依据商品资料安排 7–14 个购买问题，给每段确定商品机位、景别、证据、文案、场景和与前后段的视觉联系。相邻段尽量使用不同可见面或特写，同时延续布光、材料、色彩和字体。使用[详情页版式参考](references/templates.md)及新版风格库规划阅读顺序；用户发来的示例若用于表达偏好，只提取视觉规律。仅当用户明确要求保留该图布局时，执行逐元素测量。
2. 做约 375px 宽、可本地预览的内部线框，校对全页主次、字阶、商品位置、尺寸线端点和切片位置。完整成品任务不因线框停下；用户只要线框时交付 HTML 后停止，明确要求先看排版时展示并等待意见。
3. 先完成一张连续长图母版，再按内容节点切成用户指定屏数；用户未指定时通常 7–14 屏。依据工具的扩图、编辑和像素能力选择生成路径，把每段当作同一画面继续创作，处理重叠与接缝。不能把互不相干的单屏简单拼起来冒充连续母版。具体的接续、恢复和无损切片按[连续长图制作](references/continuous-production.md)与[长图验收](references/long-page.md)执行。
4. 让商品、环境、文字、图标、引线、局部窗和光影共同构成每段的成品视觉。标题优先利用场景留白并与商品轮廓呼应；标签和尺寸线连接到实际部件；文字对比须在手机端看得清。卡片或明确分区仅在信息关系需要时使用，不把照片与说明割裂。
5. 按用户约束完成实拍清理、规格排字或局部修正。每次检查商品锚点、款色、文案、尺寸与接缝；修改后重新导出长图和受影响切片。长图母版、逐屏图片、白底图及使用的机位素材分开交付。

## 验收与提供文件

- 每张打开检查主体是否属于正确款色，机位对应内容，标注终点是否正确，纹理与实拍是否一致，用户禁止的假人、杆子和原图标题是否已去除。核对简体中文或指定语种、品牌字样、数字、错字和模型额外添加的文案。数值未经确认就移出成品。
- 在手机宽度查看全套，确认先后顺序、读图动线、组件关联、文字安全区和相邻屏重复情况。对实际文件检查尺寸、比例、页数及是否可打开。失败的页面单独返修。续做前核对现有任务和成品，复用已验收的结果。
- 把视觉融合作为交付门槛：标题与商品是否共用场景空间、背景和光影是否自然、关键标签是否指向真实部件、不同屏是否有可辨的新视角或不同局部、文字对比和层级是否足够。逐条核对新增文字与商品证据；未经证实的功效、尺码、材质或认证不能写作事实。
- 通过的成品可逐张展示，结束时按页号提供全部独立文件。主图单列，白底图和多机位商品素材也分别给出可直接保存的入口，标明 AI 推演的机位及需核对的部位。成品交付无需压缩包。可按用户要求附顺序预览，线框按所选路径交付。
