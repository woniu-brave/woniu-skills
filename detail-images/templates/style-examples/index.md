# 十种风格的原创案例制作简报

这份索引用来制作可直接观看的商品主图与详情屏风格案例。每种风格选择一个虚构、无品牌商品；主图和详情屏各自是一张完整商品画面，文字、场景和图示须融为一体。真实上架图片由具体商品资料控制，以下案例里的尺寸、性能或配件不得被误用于真实商品。

案例画面规范：主图采用 3:4 竖构图，商品是第一视觉焦点，标题与商品共享环境空间；详情案例另选能代表整页的一个证据主题，使用不同机位，靠环境留白、字体层次、引线、局部图或图形节奏组织信息。不要把两张示例排进同一张对照板，不加模板边框、水印或“案例图”字样。图标和文字作为画面的一部分，信息卡片不作默认布局。主图与详情案分别保存于 `cases/01-极简-main.png`、`cases/01-极简-detail.png` 这样的文件名；后续技能编辑只引用对应例图作为风格参考。

## 交付规则

- 每种风格生成并保存**独立主图案例和独立详情屏案例**，总计 20 张，不用拼图代替。产品设计、文字和场景须为新创作；案例只呈现既有风格规范，不照搬用户上传的商品或现成参考图。
- 文字只用简体中文和简报中给定的短句方向。无法稳定生成准确文字时，先生成预留自然留白的完整场景，再把已审定文字以同一光影和透视关系排入画面，检查文字与场景的融合。
- 每张详情案例体现与主图不同的商品角度或局部，不是同一画面换标题。十套案例也须有构图差异，不能统一套用卡片、图标和引线位置。
- 成品加入本索引表的链接；如某例图尚未生成，不得把文字简报或 HTML 线框标成案例图。
