# woniu-skills

> 蜗牛的电商视觉技能集：给商品实拍和白底图，让 AI 做出能直接上架的主图套图和详情页分屏图。

## 这是什么？

两个面向电商卖家的 AI Agent Skill，解决同一件事——**把商品照片变成可上架的视觉素材**。主图负责在列表里被认出来，详情页负责把购买疑问逐屏讲清楚。两者共用同一套商品事实基准，可以单独使用，也可以一起做。

| 技能 | 一句话 | 典型产出 |
|---|---|---|
| **main-image** | 搜索首图 + 卖点副图 + 多 SKU 套图 | 默认 5 张主图，支持批量 CSV |
| **detail-images** | 连续长图母版 + 7–14 屏切片 + HTML 线框 | 一套手机端详情页逐屏图 |

## 核心特性

- **资料先行**：缺商品图或需求含糊时先发一次资料提醒，收齐款号、平台、卖点、素材限制再动手，不靠猜。
- **商品事实锚点**：记录结构、比例、颜色、纹理、接缝等可验收细节，区分「用户确认 / 图中可见 / AI 推演」，推演部分明确标注。
- **白底与机位准备**：先整理可核对白底图，再补齐展示所需机位；换背景、镜像、旋转不算换机位。
- **双设计路径**：无版式要求时自主设计；指定参考图时逐项测量像素，保留约定的模块顺序与图文关系。
- **手机端验收**：逐张检查款色、标注落点、文字可读性、相邻屏差异，把视觉融合作为交付门槛。
- **批量支持**：main-image 提供 CSV 清单和 Python 批量脚本，适合多 SKU 上架。

## 快速开始

把本仓库克隆到你的 Agent Skills 目录：

```bash
git clone https://github.com/woniu-brave/woniu-skills.git
```

然后在工作区指定读取对应技能入口：

- `woniu-skills/main-image/SKILL.md`
- `woniu-skills/detail-images/SKILL.md`

也可直接把某个技能文件夹复制到你的 skills 目录使用。

## 使用示例

**主图：**

> 给这款雾蓝收纳盒做一张搜索首图和四张副图，突出开口、锁扣和叠放。场景和文案由你设计。白底与实际用到的机位图也分别给我。

**详情页：**

> 用这款帆布工具包的实拍做八屏详情页，讲清开口、隔层和做工。场景、图标和标注要融入画面。文字你来拟，白底和使用的其他机位也单独给我。

两个技能一起做时，资料提醒只问一次，共用同一份商品档案。

## 交付内容

技能完成后提供可直接保存的单张图片入口：首图与副图按编号给出，详情页按页号给出逐屏图片；白底图和用到的多机位素材单独提供，AI 推演的部位会明确标注。无需压缩包。

## 目录结构

```text
woniu-skills/
├── main-image/       搜索首图、卖点副图、多 SKU 套图
│   ├── SKILL.md      技能入口
│   ├── references/   构图、风格、平台规则、批量流程等
│   └── scripts/      批量任务脚本
└── detail-images/    详情页长图母版与逐屏切片
    ├── SKILL.md      技能入口
    ├── references/   版式、连续长图制作、验收等
    ├── templates/    HTML 线框与布局参考
    ├── assets/       示例素材（SVG）
    └── scripts/      切片与分屏导出脚本
```
