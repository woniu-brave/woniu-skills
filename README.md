## 📦 安装方式

最简单的方式，是把仓库整个克隆下来：

```bash
git clone https://github.com/woniu-brave/woniu-skills.git
```

然后把用到的那个技能目录（`main-image/` 或 `detail-images/`）复制到你所用 Agent 的 skills 目录里。要装哪个就复制哪个，不用两个都放。

如果不想手动找目录，也可以把仓库里对应技能的链接直接发给 Agent，让它自己拉取：

```
帮我安装这个 skill：https://github.com/woniu-brave/woniu-skills/tree/main/main-image
```

把结尾的 `main-image` 换成 `detail-images` 就是另一个。

有一点要留意：`references/`、`scripts/`、`templates/` 这些配套目录要和 `SKILL.md` 一起复制过去。只带一个 `SKILL.md` 也能让技能被识别，但手册、脚本和模板会缺失，实际用起来会打折。

<a id="main-image"></a>

### main-image（商品主图）

> *"买家在列表里停留不到一秒，首图只做一件事：让他认出这是他要的。"*

**它只解决一件事：把商品照片变成一组能直接上架的主图。**

给它白底图、实拍或一份商品清单，它按购买问题规划首图和副图——首图让买家在列表里认出商品，副图逐张回答「为什么选它」。单品默认规划 5 张，多 SKU 用 CSV 清单批量建任务。

**为什么是「先认出，再说服」**

主图不是把卖点堆上去就完事。列表页里买家扫过一堆图，先靠首图判断「这是不是我要的东西」，点进来才靠副图判断「凭什么选你」。这两件事的顺序反了，副图做得再漂亮也没人看到。

**主图最重要的事，是别把推演当事实**

品牌、型号、规格、认证、数字必须逐字照实；看不清的结构、机位和场景属于 AI 推演，要单独标注。主图一旦把推演的细节画成确凿的样子，买家收到货就会对不上。所以它动笔前先核对商品事实，把「用户确认 / 图中可见 / AI 推演」分开。

**几件事它一定先做**

| 环节 | 做法 |
|---|---|
| 资料 | 缺图或只说「做主图」时，先发一次资料提醒：款号颜色、平台与位置、张数、卖点与素材限制 |
| 事实 | 记录结构、数量、比例、颜色、纹理、接缝，筛查人台、支架和原图营销字 |
| 白底与机位 | 场景实拍先整理白底基准再取主体；换背景、镜像、旋转、放大裁切都不算换机位 |
| 逐图 | 每张写明机位、购买问题、画面主次、可用标题事实与验收重点，只返修不通过的部分 |

**怎么用**

跟它说一句需求即可触发，下面任意一句都能用：

```
给这款雾蓝收纳盒做一张搜索首图和四张副图，突出开口、锁扣和叠放。
帮我批量做这批 SKU 的主图，清单在 products.csv。
这张副图的机位重做，其他已通过的别动。
```

产出按首图到副图顺序给出单张可直接保存的图片入口，白底与实际用到的机位图单独提供，新增场景标注为 AI 示意。信息足够时可以直接做，无法查明且会改变范围的决定才问你。

### detail-images（商品详情页）

> *"详情页不是把卖点堆上去，是替买家把「我凭什么买」一个个回答掉。"*

**它只解决一件事：把商品照片变成一套能逐屏读下去的详情页。**

给它白底图、实拍和资料，它先把购买疑问排成一条连续的阅读线，做成一张长图母版，再按内容节点切成通常 7–14 张独立图片。服装、家居、手工包装、电子产品都能用，按品类选对应图位结构。

**为什么是「连续母版」，不是「拼单屏」**

把几张互不相干的海报拼在一起，看着像详情页，读起来却是断的——前后机位对不上、光线不一致、卖点顺序乱。它的做法是先把整套当成一条连续的图来设计，确认字阶、主次和切片位置，再无损切开，保证相邻屏接得上。

**最重要的部分，是「什么问题先回答」**

买家往下滑详情页，是在按顺序消除疑虑：这是什么 → 长什么样 → 怎么用 → 靠不靠谱 → 我买哪个。问题排错了，前面的屏再精致也留不住人。所以它先规划 7–14 个购买问题，再决定每屏的机位、景别、证据和文案。

**几件事它一定先做**

| 环节 | 做法 |
|---|---|
| 资料 | 缺图或需求笼统时先发一次资料提醒，收齐款号、平台、页数、卖点、受众风格与素材限制 |
| 锚点 | 从同款输入提取可逐项验收的细节，区分「用户确认 / 图中可见 / AI 推演」，看不清的先说明缺口 |
| 双路径 | 无版式要求时自主设计并套用 10 种风格模板；指定参考图时逐项测量像素，保留约定的模块顺序 |
| 线框 | 先做约 375px 宽内部线框校对主次与切片位置；只要线框时交付 HTML 后停止 |
| 验收 | 手机宽度检查读图动线、文字安全区、相邻屏差异与去底痕迹，视觉融合作为交付门槛 |

**怎么用**

跟它说一句需求即可触发，下面任意一句都能用：

```
用这款帆布工具包的实拍做八屏详情页，讲清开口、隔层和做工。
先给我 HTML 线框，我看过排版再决定要不要出图。
第 5 屏的标注重做，其他已通过的别动。
```

产出是一张连续长图母版 + 按页号编号的逐屏独立图片，白底与实际使用的多机位素材单独提供，HTML 线框与顺序预览按需要给出。
